- Live 行情、新闻和真实 LLM：最近收尾未做真实上游全链路验收，不等于历史上从未成功，也不等于当前供应商已验证可用。
- 20 日影子测试：按用户要求暂停，不自动恢复。
- Docker：配置已校验，尚未实际构建/启动；本机 `.venv` + PostgreSQL 无需 Docker。
- 远端 CI：检查已配置，本轮未推送，不能声称远端 CI 已通过。
- 业务库完整恢复演练：业务归档只验证了可读性；已完成的恢复演练使用专用测试库，二者不同。
- 本机单用户部署边界不变；账号、多租户和自动交易不在当前范围。
