# Phase 3：20 个交易日影子验收设计

## 目标

在 Phase 2D 的审核指标基础上，连续记录真实运行结果，验证数据源稳定性、任务恢复、写作质量、人工审核效率、成本和合规边界。影子验收只记录和分析，不触发自动发布。

## 运行记录

每次影子运行记录 `run_id`、交易日、模式、Provider 状态、截止时间、最终审核状态、审核耗时、LLM 成本、降级原因和恢复结果。相同交易日可有多次独立运行，但不能覆盖历史记录。

## 黄金集与演练

- Prompt 黄金集保存输入 hash、期望结构约束、版本和回归结果，不保存 API Key 或完整模型响应。
- 恢复演练记录故障类型、检查点、恢复时间、是否丢失版本和最终状态。
- 合规记录保存规则版本、检查人、结论和备注。

## 退出门槛

- 20 个交易日记录齐全。
- 无 cutoff 之后证据进入文章的情况。
- 任务恢复演练成功，历史草稿和审计事件不丢失。
- P90 运行时长不超过 15 分钟，审核中位数不超过 5 分钟。
- 月度成本投影不超过 50 元，硬上限 100 元。
- 合规检查无未解释的阻断或自动发布调用。
