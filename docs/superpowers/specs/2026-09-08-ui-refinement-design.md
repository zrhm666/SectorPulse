# 全站视觉、状态与工作效率优化设计

日期：2026-09-08；基线：`main / 507faea`。用户已选择先视觉与状态、后运行列表和工作台效率；沿用已审查的渐进方案，当前会话实施，无子代理、无逐阶段重复确认。

## 范围与选择

采用共享设计系统修正＋局部流程调整。仅换皮无法纠正状态误导；整体重构会扩大风险且重复现有能力，因此两者均不采用。保留蓝白主题、统一导航、真实状态、自动保存、版本保护、审批限制和原有 API。

### 全局约束

- React 18、TypeScript、现有 Vite/Vitest/Playwright；不新增运行时依赖。
- 保留现有路由、SQLite/PostgreSQL 兼容与数据库结构；不修改业务数据库、.env 或 consent，不调用 Live/LLM、不恢复影子测试。
- 保留统一蓝白视觉与本机系统字体；无营销动画、无新主题、无虚构字段。
- 普通文字在实际背景上至少 4.5:1；桌面主要控件至少 40px、手机至少 44px，错误与状态不能仅靠颜色。
- 0、未知、不适用、进行中分别显示；已结束但缺耗时/成本应显示未记录，不写待完成。
- 分阶段测试与提交；最终在功能分支验收，不自动合并或推送。

## Phase 1：视觉与状态

1. 修正公共 Panel/InlineAlert/EmptyState 的布局、内边距和语义色，主色不换。加深 muted 文字与危险按钮底色以达普通文字对比要求；保留已选、焦点、禁用状态差异，移动按钮满足触控尺寸。
2. 运行类型与数据来源分开：内容/数据运行不再冒充 Provider；已保存 provider 显示“实时数据/样例演练”，缺失显示“未记录”。数据运行不产生 LLM 成本，显示“不适用”；内容运行保留真实 0 成本。
3. 候选数 0 显示 0，加载失败或无响应显示未记录。Provider/Cutoff 改为“数据来源/数据截止时间”；常见数据降级码映射为用户可理解说明，原码仍可检查，未知码不编造原因。
4. 列表加载失败提供就地重试，重试不清空筛选；保留成功内容直至刷新成功，过期状态明确提示。

## Phase 2：操作效率

### 运行历史

用“时间＋场景/运行类型”命名记录，短 ID 作为可复制/搜索的辅助标识。增加近期 ID/场景搜索、20 条分页、时间正反排序、失败/运行中/待审核快捷筛选，状态按集合归类（不能只匹配 RUNNING 而漏采集阶段）。条件及页码存于 URL；返回详情后可恢复；重新选择条件回第一页，越界页码夹取到有效范围。

当前两个 GET 各自最多返回最近 50 条。页面明确写“近期运行（每类最多 50 条）；搜索和筛选仅覆盖已加载记录”，显示已加载数量，不宣称全库总数。全历史搜索/服务端分页留为独立增强，本轮不更改仓储接口。

### 数据工作台

进行中保持进度与采集情况可见。终态时将已保存进度与采集详情归入默认收起的“处理与采集详情”，降级/错误告警始终独立可见，候选操作与结果标签页上移。详情可键盘展开；同页运行由进行中变终态时默认收起，用户仍可重新展开。标签页沿用 URL、增加方向键与 Home/End，保留数据与选择状态。

### 审核工作台

保留三栏结构与独立滚动。新增“专注草稿/恢复三栏”开关，在大屏暂时收起队列和证据；小屏仍使用原有分区标签。草稿增加章节定位，目标标题/输入获得可见焦点；textarea 根据内容高度增长，不隐藏长文，不覆盖未保存编辑。

退回原因仅在点击“退回修改”后展开，取消折叠不自动删除已输入理由；批准、退回仍走原确认弹窗和治理门禁。自动保存与版本冲突行为不改。

## Phase 3：回归与交付

以单元/页面测试验证状态和交互，浏览器验证公共颜色实际计算、错误展示、URL返回、终态折叠、专注与退回以及 1440/1024/390 宽度。生产/开发完整浏览器和前端全量测试；后端未改则以非 Live 回归检查集成安全。更新 DESIGN、当前任务计划和验收记录；所有截图标记测试样例，不把静态/Fixture 验收冒充 Live。

## 自审

本轮不是全历史查询、自动批准、批量重试或后台任务重启。不会改变草稿内容或证据决定。移动对比二次重排暂不纳入已选的两阶段重点，保留当前可用版本；应在上述高收益项完成后单独评估。
