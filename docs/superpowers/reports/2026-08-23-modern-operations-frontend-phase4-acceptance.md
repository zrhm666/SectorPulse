## 验收中修复的缺陷

1. Fixture 多次运行复用了固定 `draft_id`，第二次运行会因不可变版本冲突失败。现按 run ID 确定性生成独立产物标识，并加入连续运行回归测试。
2. 失败运行的时间线错误把全部阶段标为“已完成”。失败且无阶段事件时现显示“未完成”。
3. 标题编辑路径 `titles/0` 与存储层契约不一致。SQLite/PostgreSQL 已同时支持索引标题路径。
4. 证据理由与退回理由原先共享状态；现已分离，避免误启用退回动作。
5. 草稿保存失败后按钮可能永久处于忙碌状态；现通过 `finally` 恢复并显示全局错误反馈。
