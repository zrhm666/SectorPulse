# Phase 3 实施计划

## 1. 影子运行记录契约

- 新增影子运行、恢复演练和合规记录模型及 SQLite migration 011。
- 编写交易日唯一性、重复运行独立版本和状态转换测试。

## 2. 记录与查询 API

- 提供创建/登记影子运行、更新结果、查询 20 日进度和摘要指标接口。
- 将 Phase 2D 指标快照绑定到影子运行，避免历史数据漂移。

## 3. 黄金集与恢复演练记录

- 保存 Prompt 输入 hash、版本、回归结果和恢复演练结果。
- 前端显示影子验收进度、失败原因和未达门槛。

## 4. 20 日验收

- 使用真实网络环境逐交易日运行；本阶段不自动调用真实 LLM，除非另行确认。
- 输出 Phase 3 验收报告，明确通过、未通过和环境阻断项。
