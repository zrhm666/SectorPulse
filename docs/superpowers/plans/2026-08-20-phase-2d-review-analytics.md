# Phase 2D 实施计划

## 1. 指标领域与查询仓储

- 定义审核摘要、运行指标和导出报表 DTO。
- 从 SQLite 审计事件、Patch、治理检查和 invocation 查询聚合数据。
- 先写空数据、时间边界和多版本聚合失败测试。

## 2. 分析 API

- 实现总览、单运行指标和 JSON 报表接口。
- 固定 UTC 时间范围和确定性排序。
- 不暴露敏感字段。

## 3. 前端审核分析面板

- 在运行详情中显示审核时长、修订次数、治理阻断、核准率和导出次数。
- 提供最近运行列表与失败原因。

## 4. 验收与文档

- 执行后端全量、Ruff、前端测试和构建。
- 记录指标口径、已知空数据行为和人工发布边界。
