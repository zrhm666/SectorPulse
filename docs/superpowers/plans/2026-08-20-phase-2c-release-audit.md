# Phase 2C 实施计划

## 1. 审批与审计领域模型

- 新增 `DraftApproval`、`AuditEvent`、`DraftExport` 契约。
- 编写状态转换和不可变审计单元测试。

## 2. SQLite migration 010

- 持久化审批快照、撤销事件、导出记录和审计事件。
- 增加唯一约束与索引，更新 schema 版本测试。

## 3. 应用服务与 API

- 实现治理复检、核准、撤销、审批查询、审计查询和 JSON 导出。
- 复用现有 Markdown/TXT 导出，统一版本快照和 hash。
- 用集成测试覆盖门禁、版本绑定、撤销和导出。

## 4. 前端核准台

- 在 Draft Tab 增加核准状态、核准/撤销按钮、审计时间线和 JSON 导出。
- 核准按钮仅在治理 PASS 时可用。

## 5. 端到端验收

- 验证治理失败阻断、治理通过核准、Patch 后回退、撤销保留历史、导出审计。
- 执行后端全量测试、Ruff、前端测试和生产构建。
