# 草稿主体与修订：本批验收说明

## 已实现

- 行情快照名称写入归因上下文；模型不能替换可信名称，归因失败降级也保留名称。
- 旧 JSON 无名称仍可读；暂时无法恢复名称时，生成输入使用“行业/概念板块〔ID〕”，不猜名字。
- 写作章节与运行、大纲板块唯一绑定；标题和正文首句必须明确主体。
- 内容中的已知审核标记转为审核问题，不再通过追加“（已复核）”制造修订版本。
- `revision` 路由真实生成结构化修改集；范围、来源、证据等级、主体、系统标记和禁止用语校验后才保存新版本。
- 无变化、失败或不合法修改不递增版本；错误保存在审核问题中，不拼入正文。
- 每个新版本重新审核，拒绝草稿/版本错配报告；最多两轮修订。自动审核通过仍不等于人工批准。
- Web 外部调用日志回调不再导致内部成本统计归零；预算用尽后不发起后续模型请求。

## v1、v2、v3 的含义

这些是内容版本，不是审核次数。真实修订成功才创建下一版本；审核失败或没有实际改动不会制造新版本。历史上旧代码生成的版本不会自动重写，也不会自动去掉旧正文标记。
