# 系统提示词 YAML 模块化迁移

已确认采用递归注册表和模块目录。仅迁移运行时给 LLM 的可编辑指令文本；结构化数据、Schema、权限校验和领域回退产物保留在 Python。

1. 增强现有 PromptRegistry：递归安全读取 YAML、严格字段验证、模板变量校验、路径与内容分离的稳定哈希。
2. 六份业务提示词迁入 application/writing；Agent 纠错反馈独立 YAML；模型协议文本迁入 infrastructure/llm。
3. Agent 和模型适配器加载 YAML 组装指令，删除 Python 中重复系统提示词。
4. 验证嵌套加载、重复 ID、缺失变量、JSON 花括号和运行时实际请求；更新使用说明并回归。

参考 CAG 的 UTF-8 + SafeLoader 文件读取方式；继续使用现有注册表，以支持递归目录与版本校验。模板采用标准库 string.Template，动态值一次代入，不执行表达式。移动文件不改变已有提示词 ID、版本或原始哈希。新增协议和反馈各自版本化。修改 YAML 后重启后端生效。
