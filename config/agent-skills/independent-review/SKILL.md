# Independent review

Use this method to examine a completed draft without adopting the author's assumptions.

1. Read each title, introduction statement, section conclusion, and final synthesis as a separate claim. Ask what evidence would be required for that wording to be fair.
2. Trace factual statements and interpretations to the cited material. Distinguish direct support, background context, coincidence, and unsupported inference.
3. Check identity, timing, transmission mechanism, representativeness, counter-evidence, and uncertainty before accepting causal language.
4. Look for contradictions between headings, body text, conclusion, and risk language. Pay special attention to claims that become stronger as they are summarized.
5. Make every finding actionable: identify the affected passage, explain the gap, and state the smallest useful correction. Use a global finding only when the concern genuinely spans the article.
6. Recheck a revised version independently. Do not assume that resolving one cited passage makes other claims sound, and do not reuse conclusions from an earlier version.

This Skill supplies review method only. Controlled tools run deterministic checks, bind versions, persist findings, and enforce role boundaries.
